Key Data Flows
# Scenario Flow Security Mechanism
1 User Registration React → Auth API → PQC Engine (keypair gen) → DB (user + pubkey) ML-KEM + ML-DSA Keypair
2 Evidence Upload React → Evidence API → PQC Engine (sign + encrypt) → File Store + DB Dilithium Signature + AES-256-GCM
3 Evidence Verification React → Evidence API → PQC Engine (verify signature) → Response Signature Verification
4 Evidence Download React → Evidence API → File Store → PQC Engine (decrypt) → React AES-GCM Decrypt + Role Check
5 Admin PQID Lookup Admin Panel → Admin API → System Password Verify → DB (PQID) → Audit Log Password Gate + Audit Log
6 Court Access Grant Admin → Admin API → DB (CourtAccess record) → Audit Log entry RBAC + Audit Trail
